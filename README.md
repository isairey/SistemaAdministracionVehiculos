# 🌌 Acerca del proyecto

**Car Rental Management System** es una aplicación de escritorio desarrollada con **C# .NET Framework** orientada a la administración integral de empresas de renta de vehículos.

La plataforma permite gestionar:

- 🚗 Inventario de vehículos
- 👥 Información de clientes
- 📅 Reservaciones
- 💳 Transacciones de renta
- 🔧 Historial de mantenimiento
- 📊 Reportes administrativos
- 🧾 Facturación y pagos
- 📈 Análisis de ganancias

El sistema fue diseñado para ofrecer una solución eficiente y organizada para negocios de alquiler automotriz mediante una interfaz de escritorio moderna y robusta.
